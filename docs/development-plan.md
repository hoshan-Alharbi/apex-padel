# Development Plan — Apex Padel

المتطلبات والقرارات في [project-spec.md](project-spec.md). هذا الملف يملك: الترتيب، الأجزاء، Acceptance Criteria، والحالة.

**طريقة العمل:**
- كل جزء يُنفَّذ في Branch خاص به.
- بعد التنفيذ يُختبر على محاكي Android.
- بعدها أرسل التقرير، و**أتوقف لين تختبره**.
- لا ننتقل للجزء التالي قبل موافقتك.

**الحالات:** `Planned` → `In Progress` → `Implemented` → `Awaiting User Testing` → `Approved` / `Blocked`

**الفحوص الآلية لكل جزء:**
- `tsc --noEmit` (أخطاء TypeScript).
- `expo lint`.
- اختبارات Unit لمنطق التسعير والتقسيم (انظر الملاحظة أسفل الملف).
