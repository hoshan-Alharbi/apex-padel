## إجابات المقابلة (الدفعة 1)

- **الاسم:** Apex Padel (نفس اسم الريفرنس — قرار صاحب المشروع).
- **الألوان:** نفس ألوان الريفرنس (داكن + Volt `#D4FF00` + Cyan + Crimson) كما في `ref/apex_padel_ksa/DESIGN.md`.
- **تأكيد الحجز — طريقتين:**
  - الدفع عبر بوابة الدفع (شكلية فقط) ← تأكيد فوري.
  - بدون دفع إلكتروني ← الطلب "بانتظار التأكيد".
- **التسعير:** حسب المدة فقط (مثال: 60 د = 100 ر.س، والعرض "يبدأ من" أقل سعر). إدارة الأسعار والطلبات (داشبورد) لاحقاً، خارج النطاق الحالي.
- **البنية:** كرت الرئيسية = نادي، وداخله أكثر من ملعب يختار منها المستخدم.
- **Bottom Tabs:** الرئيسية، حجوزاتي، المفضلة، حسابي.
- **النطاق:** UI فقط ببيانات وهمية، بدون API.

## إجابات المقابلة (الدفعة 2)

- **الإضافات في الحجز:** نعم (مضرب، كرات، مويه) والإجمالي يتحرك بأنيميشن.
- **Splash:** كرة بادل تنط وترسم خطوط الملعب ← الشعار يظهر بتوهّج Volt ← انتقال بزوم ناعم للرئيسية.
- **الخط العربي:** Readex Pro، والأسعار والأوقات بـ Space Mono.
- **تسجيل الدخول:** لا يوجد. Splash ← الرئيسية مباشرة. "حسابي" شكلي بمستخدم وهمي.
- **الرئيسية:** اختيار المدينة، بحث، فلاتر (مكيّف، داخلي، خارجي)، بانر عرض، قائمة الأندية.
- **الصور:** Unsplash (رخصة تسمح بالاستخدام التجاري)، محفوظة داخل التطبيق.

## إجابات المقابلة (الدفعة 3)

- **المكتبات:** موافقة على قائمة Dependencies المقترحة.
- **جهاز التصوير:** محاكي Android.
- **اللغات:** عربي (RTL) وإنجليزي (LTR)، نسختان متطابقتان تماماً.
- **تقسيم الفاتورة (Split):**
  - اختياري.
  - تقسيم الفاتورة على اللاعبين (البادل 4 لاعبين).
  - كل صديق يوصله رابط دفع خاص يدفع منه حصته.
  - إذا ما اكتمل دفع الجميع خلال مدة محددة (مثلاً ساعة) ← استرجاع تلقائي (Auto Refund) لمن دفع.

## إجابات المقابلة (الدفعة 4)

- **تبديل اللغة:** من "حسابي"، بشاشة انتقال ثم إعادة تحميل التطبيق. المكتبة `expo-updates` معتمدة. اللغة الافتراضية: العربي.
- **عدد اللاعبين في التقسيم:** 2 أو 3 أو 4 (الافتراضي 4). كسور الهللات تُضاف لحصة صاحب الحجز.
- **اكتمال الدفع:** أول ما يكتمل المبلغ كاملاً ← الحجز يتأكد تلقائياً.
- **عدم اكتمال الدفع:**
  - صاحب الحجز يقدر "يدفع المتبقي" قبل انتهاء الساعة.
  - إذا انتهت الساعة ← الحجز يُلغى ويُسترجع المبلغ لمن دفع.
  - الوقت محجوز طوال الساعة.
- **المحاكاة:** "وضع العرض" مخفي في "حسابي" (ضغطة مطولة على الشعار). منه نحدد مين من الشركاء دفع، ونسرّع العدّاد.
- **صفحة رابط الدفع:** شاشة تعرض ما يراه الصديق عند فتح الرابط.
- **"الدفع في الملعب":** يتأكد تلقائياً بعد ثوانٍ.
- **Dockerfile:** نسخة Expo Web تُخدم بـ nginx (`react-dom` و `react-native-web` معتمدتان).
- **اسم المجلد:** يبقى `padel-app` كما هو (قرار صاحب المشروع).

## الشعار والأوبننج

- **الشعار:** `ref/logo.png` — أيقونة التطبيق، ومرسوم SVG كقطع منفصلة للأوبننج (`src/features/splash/logo.ts`).
- **الأوبننج (≈2.4 ثانية) — الشعار يتركّب من قطعه.** ألغى صاحب المشروع أوبننج المضرب 3D (2026-11-08).
  - الأدوات: `react-native-svg` + `react-native-reanimated` + `expo-haptics` فقط.
  - المعاينة المعتمدة وجدول التوقيت `TL`: [design/logo-opening-preview.html](design/logo-opening-preview.html). اعتُمدت بعد ثلاث تعديلات: المضرب والنقاط أسرع، ولفة الكورة أبطأ (easeInOutSine)، ثم الإيقاع كله أبطأ بـ `PACE = 1.5` (الجدول الأساسي 1.6 ث × 1.5) عشان تبان التفاصيل.
  - التسلسل: خطوط الملعب من المركز للأطراف ← حلقة المضرب بخط واحد والمقبض ينزلق تحتها ← النقاط بالتتابع (45ms) ← حرف A يطلع من فم المضرب مع نبضة glow ← الكورة تلف المدار وترسمه وتستقر بنطة + Haptic Light ← الشعار يصغر ويذوب في أيقونة الموقع في هيدر الرئيسية، والرئيسية تظهر.
  - كل الحركة easing، والنطات spring. الكود: `src/features/splash/` (التوقيت في `timeline.ts`؛ السرعة الكلية تتعدل من `PACE` فقط).
  - الرئيسية تُركَّب خلف الأوبننج أولاً، والأوبننج يبدأ بعد أول layout لها (أو بعد 1.5 ث كحد أقصى)، عشان تركيبها ما يجمّد الإطارات.
- **التخطي:** ضغطة في أي وقت تقفز لمرحلة الخروج (آخر 0.3 ث). "تقليل الحركة" مفعّل ← الشعار ثابت 0.6 ث ثم الرئيسية مباشرة.

# المواصفات

## الهدف والمستخدم
تطبيق جوال عربي (RTL) لحجز ملاعب البادل في السعودية. المستخدم: لاعب يبحث عن ملعب ويحجز وقتاً. هذه النسخة **UI فقط** ببيانات وهمية لحلقة تيك توك، والباك اند (إدارة الطلبات، داشبورد الأسعار) لاحقاً.

## User Journey الأساسي
1. **Splash** متحرك ← الرئيسية.
2. **الرئيسية:** تصفّح الأندية (صورة، تقييم، الحي/المدينة، المميزات، "يبدأ من 100 ر.س").
3. **تفاصيل النادي:** صور، معلومات، مرافق، قائمة الملاعب، زر "احجز".
4. **الحجز:**
   - اختيار الملعب.
   - اختيار التاريخ.
   - اختيار المدة (60/90/120، والسعر لكل مدة).
   - اختيار وقت من الأوقات المتاحة.
   - الإضافات.
   - الإجمالي يتحدث مباشرة.
5. **الدفع:** اختيار الطريقة:
   - **ادفع الآن** (مدى / Apple Pay / STC Pay): بوابة دفع شكلية تعرض "جارٍ المعالجة" ثم **تأكيد فوري**.
   - **الدفع في الملعب:** الطلب يصير **بانتظار التأكيد**.
   - **تقسيم الفاتورة (اختياري):**
     - يتفعّل مع "ادفع الآن" فقط.
     - صاحب الحجز يدفع حصته.
     - كل شريك يوصله رابط دفع (مشاركة عبر واتساب).
     - الحجز "بانتظار دفع الشركاء" مع عدّاد تنازلي (ساعة).
     - يكتمل الدفع ← مؤكد. ينتهي الوقت ← إلغاء واسترجاع تلقائي لمن دفع.
6. **شاشة النتيجة:**
   - تأكيد بأنيميشن، مع بطاقة الحجز (رقم الحجز، الوقت، الملعب).
   - أو حالة "بانتظار التأكيد".
7. **حجوزاتي:** القادمة والسابقة مع حالة كل حجز.

## الشاشات
| الشاشة | Route | المحتوى |
|---|---|---|
| Splash | (داخل root layout) | الشعار يتركّب من قطعه (انظر "الشعار والأوبننج") |
| الرئيسية | `(tabs)/index` | المدينة، البحث، الفلاتر، بانر أقرب حجز (من الحالة)، قائمة الأندية |
| حجوزاتي | `(tabs)/bookings` | تبويب القادمة/السابقة، بطاقات بحالة |
| المفضلة | `(tabs)/favorites` | الأندية المحفوظة (كل المدن) |
| حسابي | `(tabs)/account` | مستخدم وهمي، إحصائيات، إعدادات شكلية. ضغطة مطولة على الشعار = وضع العرض |
| تفاصيل النادي | `club/[id]` | Hero بصور و Parallax، المعلومات، المرافق، الملاعب ومواصفاتها، الآراء، سياسة الإلغاء، زر ثابت بالأسفل |
| الحجز | `book/[clubId]?court=` | الملعب، التاريخ، المدة، الأوقات، الإضافات، الإجمالي الثابت |
| الدفع | `checkout` | ملخص، طرق الدفع، تقسيم الفاتورة، Sheet بوابة الدفع الشكلية |
| التذكرة (النتيجة + تفاصيل الحجز) | `booking/[id]?fresh=1` | شاشة واحدة: الحالة، تذكرة الدخول، إجراءات سريعة، ملخص الدفع. `fresh=1` بعد الدفع (علامة صح + زر "تم") |
| متابعة التقسيم | `split/[id]` | العدّاد، حالة كل شريك، إرسال الرابط، ادفع المتبقي |
| صفحة رابط الدفع | `pay/[bookingId]/[shareId]` | ما يراه الشريك (`apexpadel://pay/...`) |

**الحالات لكل شاشة:**
- **Loading:** Skeleton بتأخير وهمي قصير في الرئيسية.
- **Empty:** بحث بدون نتائج، مفضلة فاضية، حجوزات فاضية.
- **Success:** الحالة الطبيعية لكل شاشة.
- **Error:** غير منطبق فعلياً بدون API. نجهّز مكوّن خطأ بسيط فقط للحالة الفارغة لنادٍ غير موجود.

## نظام الحركة (Motion)
- **الضغط:** كل عنصر قابل للضغط يتقلص (scale 0.97) مع Spring، وفيه Haptic خفيف للأفعال المهمة.
- **القوائم:** دخول متتابع (FadeInDown مع stagger).
- **الاختيار:** تبديل المدة والوقت بانتقال لوني ناعم وتوهّج Volt.
- **الأرقام:** عدّاد للسعر الإجمالي عند تغييره.
- **تفاصيل النادي:** Parallax للصورة، والهيدر يتحول لشريط ثابت مع التمرير.
- **التأكيد:** علامة صح ترسم نفسها بـ SVG، وانفجار جزيئات خفيف.
- **الانتظار:** نبض (pulse) لحالة "بانتظار التأكيد".
- **الأداء:** الأنيميشن كله على الـ UI thread بـ Reanimated.
- **Reduced Motion:** نحترم إعداد تقليل الحركة في الجهاز.

## Initial Architecture
```
src/
  app/                ← expo-router (الشاشات والـ Routing فقط — موقعه الافتراضي في SDK 58)
    _layout.tsx       ← الخطوط، RTL، Splash، Providers، Root Stack
    (tabs)/_layout.tsx← Tabs + TabBar المخصص
  features/
    clubs/            ← كروت الأندية، الفلاتر، تفاصيل النادي
    booking/          ← منطق التسعير، اختيار الوقت، الإضافات، الدفع
    bookings/         ← قائمة حجوزاتي
    favorites/
  components/         ← مشترك فعلياً فقط (PressableScale, Button, Chip, Price, Skeleton)
  theme/              ← tokens (ألوان، خطوط، مسافات) + tailwind config
  data/               ← بيانات وهمية (أندية، ملاعب، أسعار، أوقات)
  state/              ← Context + useReducer (الحجوزات، المفضلة)
  utils/              ← تنسيق الريال والوقت بالعربي
```
- **الـ State:**
  - في الذاكرة فقط (Context + useReducer)، بدون مكتبة state.
  - الحجوزات والمفضلة ترجع للبيانات الافتراضية عند إعادة فتح التطبيق.
- **منطق التسعير:**
  - موجود في `features/booking`، ومنفصل عن الـ UI.
  - جاهز يتبدّل بـ API لاحقاً.

## Assumptions
- **الأندية والمدن:** 6 أندية وهمية موزعة على الرياض وجدة والخبر، وكل نادي فيه 2–4 ملاعب.
- **الأسعار:** حسب المدة، 60 د = 100 ر.س، و90 = 140، و120 = 180. تختلف قليلاً بين الأندية، والعرض يكون "يبدأ من" أقل سعر.
- **الأوقات:**
  - من 4 العصر إلى 2 الفجر.

## Risks
- **تبديل الاتجاه (RTL↔LTR) في React Native:** يتطلب `I18nManager.forceRTL` مع إعادة تشغيل التطبيق. التبديل الفوري بدون إعادة تشغيل غير موثوق مع الـ Navigation والقوائم الأفقية.
- **Blur على Android:** `expo-blur` على Android تجريبي وأثقل. نستخدم خلفية شبه شفافة كبديل على Android إذا كان الأداء سيئاً في المحاكي.
- **RTL على محاكي Android:** يحتاج `I18nManager.forceRTL(true)` مع إعادة تحميل أول مرة. نعالجها في F1 ونتأكد على المحاكي.
- **المحاكاة الزمنية:** العدّاد وحالات الدفع في الذاكرة فقط. إغلاق التطبيق يعيد البيانات الوهمية للوضع الافتراضي.
- **NativeWind مع Reanimated 4 / SDK 58:** لازم نتحقق من التوافق عند الإعداد. لو صار تعارض، أبلغك قبل أي حل بديل.
- **الأداء:** أنيميشن كثير مع الصور على أجهزة Android الضعيفة. نخفف بـ `expo-image` والأنيميشن على الـ UI thread.
